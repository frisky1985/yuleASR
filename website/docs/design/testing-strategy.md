# 测试策略设计

## 测试金字塔

```
        ┌───────────────────────────┐
        │    系统测试 (HIL)     │
        └───────────────────────────┘
        ┌───────────────────────────┐
        │    集成测试           │
        └───────────────────────────┘
        ┌───────────────────────────┐
        │    单元测试           │
        └───────────────────────────┘
        ┌───────────────────────────┐
        │    静态分析           │
        └───────────────────────────┘
```

## 测试框架

### 单元测试

- **框架**: CMocka
- **覆盖率目标**: >80%
- **模式**: TDD (测试驱动开发)

### 集成测试

- **测试对象**: 模块间交互
- **重点**: 数据流、时序

## 测试类型

| 类型 | 目的 | 工具 |
|******|******|******|
| 功能测试 | 验证功能正确性 | CMocka |
| 回归测试 | 防止代码回归 | CI |
| 性能测试 | 验证性能指标 | 自定义工具 |
| 静态分析 | 代码质量 | MISRA Checker |
