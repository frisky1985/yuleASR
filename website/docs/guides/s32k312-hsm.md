# S32K312 HSM使用指南

> **文档版本**: v1.0  
> **适用芯片**: NXP S32K312  
> **参考规范**: AutoSAR CRYIF/CRYPTO/CSEC  
> **最后更新**: 2026-05-01

***

## 1. S32K312 HSM概述

### 1.1 硬件安全模块特性

S32K312 集成专用 **Hardware Security Module (HSM)**，提供独立于主Cortex-M7内核的硬件安全处理能力：

| 特性 | 描述 |
|:***--|:***--|
| **独立安全域** | HSM子系统与主CPU隔离，防止软件攻击 |
| **安全启动** | 支持Secure Boot，验证固件完整性 |
| **密钥隔离** | 安全密钥存储，防止未授权访问 |
| **加速引擎** | 专用密码学硬件加速器 |

### 1.2 支持的密码学算法

| 算法类别 | 支持算法 | 实现方式 |
|:*********|:*********|:*********|
| **对称加密** | AES-128/256 | 硬件加速 |
| **非对称加密** | ECC P-256 | 硬件加速 |
| **哈希算法** | SHA-256 | 硬件加速 |
| **消息认证** | CMAC, HMAC | 硬件加速 |
| **随机数** | TRNG | 硬件生成 |

### 1.3 安全功能

- **安全启动 (Secure Boot)**: 验证BootROM和应用程序签名
- **密钥存储**: 安全密钥槽位，支持密钥派生
- **安全调试**: 可配置调试端口访问权限
- **生命周期管理**: 支持不同安全生命周期状态

### 4.1 HSM初始化配置

```c
/*=============================================================================
 * HSM 初始化配置 (CryIf/Crypto 集成)
 *=============================================================================*/

#include "CryIf.h"
#include "Crypto.h"
#include "Csm.h"

/* HSM 配置结构体 */
const CryIf_ChannelConfigType CryIf_ChannelConfig[] = {
    {
        .channelId = CRYIF_CHANNEL_HSM_0,
        .cryptoDriverId = 0,           /* HSM Crypto Driver */
        .cryptoKeyId = 0,              /* 默认密钥 */
        .priority = 1                  /* 通道优先级 */
    }
};

/* Crypto 驱动配置 */
const Crypto_DriverObjectType Crypto_HsmDriver = {
    .driverId = 0,
    .hardwareInstance = CRYPTO_HW_INSTANCE_HSM,
    .queueSize = 16,                   /* 作业队列大小 */
    .priorityLevel = CRYPTO_PRIORITY_HIGH
};

/*=============================================================================
 * 初始化流程
 *=============================================================================*/
Std_ReturnType Hsm_Init(void)
{
    Std_ReturnType result;
    
    /* 1. 初始化 Crypto 层 */
    result = Crypto_Init(&Crypto_Config);
    if (result != E_OK) {
        return E_NOT_OK;
    }
    
    /* 2. 初始化 CryIf 接口层 */
    result = CryIf_Init(&CryIf_Config);
    if (result != E_OK) {
        return E_NOT_OK;
    }
    
    /* 3. 初始化 CSM 服务层 */
    result = Csm_Init(&Csm_Config);
    if (result != E_OK) {
        return E_NOT_OK;
    }
    
    /* 4. HSM 自检 */
    result = Hsm_SelfTest();
    if (result != E_OK) {
        return E_NOT_OK;
    }
    
    return E_OK;
}

/* HSM 自检函数 */
Std_ReturnType Hsm_SelfTest(void)
{
    uint8 testData[16] = {0};
    uint8 encrypted[16] = {0};
    uint32 resultLen = 16;
    
    /* 执行已知答案测试 (KAT) */
    return Csm_Encrypt(
        CSM_JOB_ID_SELFTEST_AES,
        CRYPTO_OPERATIONMODE_SINGLECALL,
        testData,
        16,
        encrypted,
        &resultLen
    );
}
```

### 4.3 安全启动配置

```c
/*=============================================================================
 * 安全启动配置
 *=============================================================================*/

#include "Hsm_SecureBoot.h"

/* 安全启动配置结构体 */
const Hsm_SecureBootConfigType SecureBoot_Config = {
    .bootMode = HSM_BOOT_STRICT,       /* 严格模式: 验证失败则停止启动 */
    .verifyApp = TRUE,                 /* 验证应用程序 */
    .verifyUpdate = TRUE,              /* 验证OTA更新 */
    .rollbackProtection = TRUE,        /* 启用回滚保护 */
    .maxRollbackVersion = 10           /* 最大回滚版本 */
};

/* 固件头部结构 (用于签名验证) */
typedef struct {
    uint32 magic;                       /* 魔数: 'FIRM' */
    uint32 version;                     /* 固件版本 */
    uint32 codeSize;                    /* 代码大小 */
    uint32 codeOffset;                  /* 代码偏移 */
    uint8  hash[32];                    /* SHA-256 哈希 */
    uint8  signature[64];               /* ECC P-256 签名 */
    uint8  reserved[16];                /* 保留 */
} Firmware_HeaderType;

/*=============================================================================
 * 安全启动流程
 *=============================================================================*/
Std_ReturnType Hsm_PerformSecureBoot(void)
{
    Std_ReturnType result;
    Firmware_HeaderType* header;
    uint8 computedHash[32];
    
    /* 1. 读取固件头部 */
    header = (Firmware_HeaderType*)FIRMWARE_BASE_ADDR;
    
    /* 2. 验证魔数 */
    if (header->magic != FIRMWARE_MAGIC) {
        Hsm_SecurityViolation(HSM_ERR_INVALID_MAGIC);
        return E_NOT_OK;
    }
    
    /* 3. 计算代码段哈希 */
    result = Hsm_CalculateHash(
        (uint8*)(FIRMWARE_BASE_ADDR + header->codeOffset),
        header->codeSize,
        computedHash
    );
    if (result != E_OK) {
        return E_NOT_OK;
    }
    
    /* 4. 验证哈希匹配 */
    if (memcmp(computedHash, header->hash, 32) != 0) {
        Hsm_SecurityViolation(HSM_ERR_HASH_MISMATCH);
        return E_NOT_OK;
    }
    
    /* 5. 验证签名 */
    result = Hsm_VerifySignature(
        HSM_KEY_FIRMWARE_SIGN,          /* 固件签名公钥 */
        header->hash,
        32,
        header->signature,
        64
    );
    if (result != E_OK) {
        Hsm_SecurityViolation(HSM_ERR_INVALID_SIGNATURE);
        return E_NOT_OK;
    }
    
    /* 6. 检查版本 (回滚保护) */
    if (!Hsm_CheckVersion(header->version)) {
        Hsm_SecurityViolation(HSM_ERR_VERSION_ROLLBACK);
        return E_NOT_OK;
    }
    
    /* 7. 安全启动通过，跳转到应用程序 */
    Hsm_JumpToApplication(FIRMWARE_BASE_ADDR + header->codeOffset);
    
    return E_OK;
}
```

### 5.1 硬件AES加密示例

```c
/*=============================================================================
 * 硬件AES-256 CBC加密示例
 *=============================================================================*/

#include "Csm.h"

#define AES_BUFFER_SIZE     256
#define AES_BLOCK_SIZE      16

typedef struct {
    uint8 key[32];
    uint8 iv[16];
    uint8 input[AES_BUFFER_SIZE];
    uint8 output[AES_BUFFER_SIZE];
    uint32 dataLen;
} Aes_ContextType;

/*=============================================================================
 * AES-256 CBC 加密
 *=============================================================================*/
Std_ReturnType Hsm_Aes256_Encrypt(
    const uint8* plaintext,
    uint32 plainLen,
    const uint8* key,
    const uint8* iv,
    uint8* ciphertext,
    uint32* cipherLen
)
{
    Std_ReturnType result;
    Crypto_VerifyResultType verifyResult;
    
    /* 1. 设置密钥 */
    result = Csm_KeyElementSet(
        HSM_KEY_AES_OPERATION,          /* 操作密钥ID */
        CRYPTO_KEYELEMENT_AES_KEY,
        key,
        32                              /* AES-256 */
    );
    if (result != E_OK) {
        return E_NOT_OK;
    }
    
    /* 2. 设置IV */
    result = Csm_KeyElementSet(
        HSM_KEY_AES_OPERATION,
        CRYPTO_KEYELEMENT_IV,
        iv,
        16
    );
    if (result != E_OK) {
        return E_NOT_OK;
    }
    
    /* 3. 配置加密作业 */
    result = Csm_Encrypt(
        CSM_JOB_AES256_CBC,             /* 预配置作业ID */
        CRYPTO_OPERATIONMODE_SINGLECALL,
        plaintext,
        plainLen,
        ciphertext,
        cipherLen
    );
    
    return result;
}

/*=============================================================================
 * AES-256 GCM 认证加密 (推荐用于安全通信)
 *=============================================================================*/
Std_ReturnType Hsm_Aes256_Gcm_Encrypt(
    const uint8* plaintext,
    uint32 plainLen,
    const uint8* aad,                   /* 附加认证数据 */
    uint32 aadLen,
    const uint8* key,
    const uint8* nonce,
    uint8* ciphertext,
    uint8* tag                          /* 认证标签 (16字节) */
)
{
    Std_ReturnType result;
    Crypto_JobPrimitiveInputOutputType inputOutput = {
        .inputPtr = plaintext,
        .inputLength = plainLen,
        .secondaryInputPtr = aad,
        .secondaryInputLength = aadLen,
        .tertiaryInputPtr = nonce,
        .tertiaryInputLength = 12,      /* GCM标准nonce长度 */
        .outputPtr = ciphertext,
        .outputLength = plainLen,
        .secondaryOutputPtr = tag,
        .secondaryOutputLength = 16     /* GCM标签长度 */
    };
    
    /* 加载密钥 */
    Csm_KeyElementSet(HSM_KEY_AES_GCM, CRYPTO_KEYELEMENT_AES_KEY, key, 32);
    
    /* 执行GCM加密 */
    result = Csm_JobKeySetMode(
        CSM_JOB_AES256_GCM,
        HSM_KEY_AES_GCM,
        CRYPTO_ALGOMODE_GCM
    );
    if (result != E_OK) {
        return E_NOT_OK;
    }
    
    result = Csm_Encrypt(
        CSM_JOB_AES256_GCM,
        CRYPTO_OPERATIONMODE_SINGLECALL | CRYPTO_OPERATIONMODE_START | CRYPTO_OPERATIONMODE_FINISH,
        plaintext,
        plainLen,
        ciphertext,
        &inputOutput.outputLength
    );
    
    /* 获取认证标签 */
    if (result == E_OK) {
        memcpy(tag, inputOutput.secondaryOutputPtr, 16);
    }
    
    return result;
}
```

### 5.2 硬件ECC签名示例

```c
/*=============================================================================
 * 硬件ECC P-256签名示例
 *=============================================================================*/

#include "Csm.h"
#include "Csm_Callback.h"

#define ECC_P256_PRIVATE_KEY_SIZE   32
#define ECC_P256_PUBLIC_KEY_SIZE    64
#define ECC_P256_SIGNATURE_SIZE     64

/*=============================================================================
 * 生成ECC密钥对
 *=============================================================================*/
Std_ReturnType Hsm_Ecc_GenerateKeyPair(uint32 keyId)
{
    Std_ReturnType result;
    
    /* 使用HSM生成密钥对 */
    result = Csm_RandomSeed(
        CSM_RNG_ID_TRNG,
        NULL,                           /* HSM使用内部TRNG */
        0
    );
    if (result != E_OK) {
        return E_NOT_OK;
    }
    
    /* 生成ECC P-256密钥对 */
    result = Csm_KeyGenerate(
        keyId,
        CRYPTO_ALGOFAM_ECCNIST,
        CRYPTO_ALGOMODE_NOT_SET,
        CRYPTO_KEYGENERATE_KEYPAIR
    );
    
    return result;
}

/*=============================================================================
 * ECC P-256 签名
 *=============================================================================*/
Std_ReturnType Hsm_Ecc_Sign(
    uint32 keyId,
    const uint8* messageHash,
    uint32 hashLen,
    uint8* signature,
    uint32* sigLen
)
{
    Std_ReturnType result;
    
    /* 验证哈希长度 */
    if (hashLen != 32) {                /* P-256使用256位哈希 */
        return E_NOT_OK;
    }
    
    /* 执行签名 */
    result = Csm_SignatureGenerate(
        CSM_JOB_ECC_SIGN,
        CRYPTO_OPERATIONMODE_SINGLECALL,
        keyId,
        messageHash,
        hashLen,
        signature,
        sigLen,
        CRYPTO_SIGNATUREGENERATE_ECNIST
    );
    
    return result;
}

/*=============================================================================
 * ECC P-256 验证签名
 *=============================================================================*/
Std_ReturnType Hsm_Ecc_Verify(
    uint32 keyId,
    const uint8* messageHash,
    uint32 hashLen,
    const uint8* signature,
    uint32 sigLen,
    Crypto_VerifyResultType* verifyResult
)
{
    Std_ReturnType result;
    
    result = Csm_SignatureVerify(
        CSM_JOB_ECC_VERIFY,
        CRYPTO_OPERATIONMODE_SINGLECALL,
        keyId,
        messageHash,
        hashLen,
        signature,
        sigLen,
        CRYPTO_SIGNATUREVERIFY_ECNIST,
        verifyResult
    );
    
    return result;
}

/*=============================================================================
 * 使用示例: 安全诊断通信签名
 *=============================================================================*/
void Example_SecureDiagnosticSign(void)
{
    uint8 diagData[] = {0x22, 0xF1, 0x90};  /* 读DID请求 */
    uint8 hash[32];
    uint8 signature[64];
    uint32 sigLen = sizeof(signature);
    Std_ReturnType result;
    
    /* 1. 计算数据哈希 (使用HSM SHA-256) */
    Csm_Hash(
        CSM_JOB_SHA256,
        CRYPTO_OPERATIONMODE_SINGLECALL,
        diagData,
        sizeof(diagData),
        hash,
        &sigLen
    );
    
    /* 2. 使用设备私钥签名 */
    result = Hsm_Ecc_Sign(
        HSM_KEY_ECC_DEVICE_PRIVATE,
        hash,
        32,
        signature,
        &sigLen
    );
    
    if (result == E_OK) {
        /* 3. 发送带签名的诊断请求 */
        Diag_SendSecureRequest(diagData, sizeof(diagData), signature, sigLen);
    }
}

/*=============================================================================
 * 使用示例: ECDH密钥协商 (用于安全会话建立)
 *=============================================================================*/
Std_ReturnType Hsm_Ecdh_KeyAgreement(
    uint32 localKeyId,
    const uint8* remotePublicKey,
    uint8* sharedSecret
)
{
    Std_ReturnType result;
    uint32 secretLen = 32;              /* P-256协商结果 */
    
    /* 导入对方公钥到临时槽位 */
    Csm_KeyElementSet(
        HSM_KEY_TEMP_REMOTE_PUB,
        CRYPTO_KEYELEMENT_ECC_PUBLIC_KEY,
        remotePublicKey,
        64
    );
    
    /* 执行ECDH密钥协商 */
    result = Csm_KeyExchangeCalcSecret(
        CSM_JOB_ECDH,
        localKeyId,
        HSM_KEY_TEMP_REMOTE_PUB,
        sharedSecret,
        &secretLen
    );
    
    return result;
}
```

### 5.3 安全密钥存储示例

```c
/*=============================================================================
 * 安全密钥存储使用示例
 *=============================================================================*/

#include "Csm.h"
#include "Crypto_KeyManagement.h"

/* 密钥槽位定义 */
#define HSM_KEY_SLOT_PROVISIONING   0   /* 出厂密钥 */
#define HSM_KEY_SLOT_DEVICE_UNIQUE  1   /* 设备唯一密钥 */
#define HSM_KEY_SLOT_SESSION        2   /* 会话密钥 */
#define HSM_KEY_SLOT_UPDATE         3   /* 更新密钥 */

/*=============================================================================
 * 密钥派生 (KDF) - 从主密钥派生会话密钥
 *=============================================================================*/
Std_ReturnType Hsm_DeriveSessionKey(
    uint32 masterKeyId,
    const uint8* context,
    uint32 contextLen,
    uint32 sessionKeyId
)
{
    Std_ReturnType result;
    Crypto_KeyDeriveConfigType deriveConfig = {
        .kdfAlgorithm = CRYPTO_ALGOFAM_KDFNIST,
        .sourceKeyId = masterKeyId,
        .targetKeyId = sessionKeyId,
        .saltPtr = context,
        .saltLength = contextLen,
        .iterations = 10000             /* PBKDF2迭代次数 */
    };
    
    /* 使用NIST SP 800-108 KDF派生密钥 */
    result = Csm_KeyDerive(
        CSM_JOB_KEY_DERIVE,
        &deriveConfig
    );
    
    return result;
}

/*=============================================================================
 * 密钥包装 (Key Wrapping) - 安全导出密钥
 *=============================================================================*/
Std_ReturnType Hsm_WrapKey(
    uint32 keyToWrapId,
    uint32 wrappingKeyId,
    uint8* wrappedKey,
    uint32* wrappedLen
)
{
    Std_ReturnType result;
    
    /* 使用AES-KW (RFC 3394) 或 AES-KWP包装密钥 */
    result = Csm_KeyExchangeCalcSecret(
        CSM_JOB_KEY_WRAP,
        keyToWrapId,
        wrappingKeyId,
        wrappedKey,
        wrappedLen
    );
    
    return result;
}

/*=============================================================================
 * 密钥导入 - 安全导入外部密钥
 *=============================================================================*/
Std_ReturnType Hsm_ImportWrappedKey(
    const uint8* wrappedKey,
    uint32 wrappedLen,
    uint32 unwrappingKeyId,
    uint32 targetKeyId
)
{
    Std_ReturnType result;
    
    /* 解包并导入密钥到安全存储 */
    result = Csm_KeyCopy(
        unwrappingKeyId,
        targetKeyId
    );
    
    /* 实际解密操作 */
    if (result == E_OK) {
        result = Csm_Decrypt(
            CSM_JOB_KEY_UNWRAP,
            CRYPTO_OPERATIONMODE_SINGLECALL,
            wrappedKey,
            wrappedLen,
            NULL,                       /* 直接写入目标密钥槽 */
            &wrappedLen
        );
    }
    
    return result;
}

/*=============================================================================
 * 密钥使用计数和生命周期管理
 *=============================================================================*/
typedef struct {
    uint32 keyId;
    uint32 usageCount;
    uint32 maxUsageCount;
    boolean isActive;
} Hsm_KeyLifecycleType;

/* 检查密钥使用限制 */
Std_ReturnType Hsm_CheckKeyUsageLimit(uint32 keyId)
{
    Hsm_KeyLifecycleType* lifecycle;
    
    /* 获取密钥生命周期信息 */
    lifecycle = Hsm_GetKeyLifecycle(keyId);
    if (lifecycle == NULL) {
        return E_NOT_OK;
    }
    
    /* 检查是否超出使用限制 */
    if (lifecycle->usageCount >= lifecycle->maxUsageCount) {
        /* 密钥已耗尽，标记为无效 */
        Hsm_InvalidateKey(keyId);
        return CSM_E_KEY_EXPIRED;
    }
    
    /* 递增使用计数 */
    lifecycle->usageCount++;
    
    return E_OK;
}

/*============================================================================*
 * 使用示例: 安全OTA密钥更新流程
 *=============================================================================*/
Std_ReturnType Example_SecureOtaKeyUpdate(void)
{
    Std_ReturnType result;
    uint8 wrappedUpdateKey[256];
    uint32 wrappedLen;
    
    /* 1. 验证OTA包签名 (使用当前固件密钥) */
    result = Hsm_VerifyOtaSignature();
    if (result != E_OK) {
        return E_NOT_OK;                /* OTA包验证失败 */
    }
    
    /* 2. 从OTA包中提取加密的新密钥 */
    Ota_GetWrappedKey(wrappedUpdateKey, &wrappedLen);
    
    /* 3. 使用设备私钥解密会话密钥 (已建立的安全通道) */
    uint8 sessionKey[32];
    result = Hsm_DecryptSessionKey(wrappedUpdateKey, wrappedLen, sessionKey);
    
    /* 4. 使用会话密钥解包新固件密钥 */
    result = Hsm_ImportWrappedKey(
        wrappedUpdateKey + 32,          /* 加密的新密钥 */
        wrappedLen - 32,
        HSM_KEY_SESSION,                /* 会话密钥ID */
        HSM_KEY_SLOT_UPDATE             /* 目标槽位 */
    );
    
    /* 5. 验证新密钥完整性 */
    result = Hsm_VerifyKeyIntegrity(HSM_KEY_SLOT_UPDATE);
    
    /* 6. 激活新密钥 (原子操作) */
    if (result == E_OK) {
        Hsm_ActivateKey(HSM_KEY_SLOT_UPDATE, HSM_KEY_SLOT_ACTIVE);
    }
    
    return result;
}
```

## 6. 故障排除

### 6.1 常见问题与解决方案

| 问题描述 | 可能原因 | 解决方案 |
|:*********|:*********|:*********|
| **HSM初始化失败** | 电源/时钟不稳定 | 检查HSM电源域和时钟配置 |
| | HSM固件损坏 | 重新烧录HSM固件 |
| | 安全状态锁定 | 检查芯片生命周期状态 |
| **密钥导入失败** | 密钥格式错误 | 验证密钥长度和格式 |
| | 密钥槽位已满 | 清除或更换密钥槽位 |
| | 访问权限不足 | 检查密钥权限配置 |
| **加密操作超时** | 数据量过大 | 分块处理大数据 |
| | HSM忙 | 检查作业队列状态 |
| | 中断未使能 | 配置HSM中断 |
| **签名验证失败** | 哈希算法不匹配 | 确保使用正确的哈希算法 |
| | 公钥错误 | 验证公钥正确性 |
| | 数据被篡改 | 检查传输完整性 |
| **随机数质量差** | TRNG熵源问题 | 等待TRNG初始化完成 |
| | 熵池耗尽 | 增加熵收集时间 |

- [ ] HSE固件已正确烧录
- [ ] HSM时钟配置正确 (通常48MHz)

### 8.2 性能优化建议

1. **批量处理**: 合并小数据块操作
2. **异步操作**: 使用异步API提高吞吐量
3. **密钥缓存**: 频繁使用的密钥保持在内存
4. **队列管理**: 监控队列水位线，避免溢出
5. **DMA传输**: 大数据量使用DMA传输
