## 2. 核心卖点提炼

### 2.1 从座椅 Demo 可引出的 5 大卖点

| # | 卖点 | 证据来源 | 对应受众 |
|---|------|----------|----------|
| 1 | **AUTOSAR 架构成熟度** — BSW 9-stage 初始化 + MCAL 分层 | `main.c` 初始化序列 / 目录结构 | 核心圈 |
| 2 | **S32K312 + ARM GCC 开箱即用** — 无需商业 IDE 即可编译烧录 | `CMakeLists.txt` / 构建文档 | 核心圈 + 辐射圈 |
| 3 | **零动态内存、MISRA 友好、C99 标准** — 符合车规级编码规范 | 无 malloc/free / static 全局 / Q10 定点 | 辐射圈 |
| 4 | **完整的安全/诊断策略** — 过流/堵转/限位/过温/欠压 12 种故障诊断 | `Seat_Cfg.h` 错误码定义 | 功能安全工程师 |
| 5 | **6 自由度 + 加热 + 记忆 + LIN/CAN 通信** — 覆盖真实座椅 ECU 全部功能 | README 功能表 / 协议定义 | 影响圈 + 溢出圈 |

### 2.2 差异化对比

| 维度 | yuleASR Seat Demo | 竞品 A（商业方案） | 竞品 B（其他开源） |
|------|-------------------|--------------------|--------------------|
| 许可 | MIT（完全开放） | 商业许可 | GPL/LGPL 混用 |
| 芯片支持 | S32K312 (Cortex-M7) | 仅限自家 MCU | 多芯片但深度不足 |
| 开发环境 | arm-none-eabi-gcc + CMake | 商业 IDE 绑定 | 部分可 GCC 但需适配 |
| 构建即用 | 是 — 一步编译 | 需安装复杂 SDK | 依赖多、配置冗长 |
| ISO 26262 | 架构准备（锁步 + WDT） | 认证级 | 无 |
