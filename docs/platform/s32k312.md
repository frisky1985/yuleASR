## 1 概述

### 1.1 平台信息

| 参数 | 值 |
|------|-----|
| MCU | NXP S32K312 |
| 核心 | ARM Cortex-M4F (单核) |
| 最大频率 | 80 MHz |
| FPU | 单精度硬件 FPU (VFPv4) |
| SRAM | 64 KB (SRAM_L 32 KB + SRAM_H 32 KB) |
| Flash | 512 KB (程序) + 16 KB (数据 Flash / EEPROM 模拟) |
| 安全特性 | MPU (8 区域), ECC (RAM/Flash), Lockstep 双核锁步 |
| HSE | HSE_B (硬件安全引擎, 密码加速) |
| 温度范围 | -40°C ~ 125°C (车规) |
| 通信外设 | CAN-FD ×3, LIN ×2, SPI ×3, I2C ×2, UART ×4 |
| 定时器 | PIT ×4, FlexTimer ×8, LPIT ×1, WDOG ×1 |

### 1.2 开发环境

| 组件 | 版本 | 说明 |
|------|:----:|------|
| 交叉编译器 | arm-none-eabi-gcc 13.2 | GNU Arm Embedded Toolchain |
| 调试器 | S32 Design Studio / pyOCD | OpenSDA 调试接口 |
| 链接器 | arm-none-eabi-ld 2.42 | GNU LD |
| 硬件调试器 | PEMicro Multilink | — |
| RTOS | AUTOSAR OS (OSEK) | 基于 FreeRTOS 适配 |

## 2 构建说明

### 2.1 前置条件

```bash
# 1. 安装 ARM GCC 工具链
brew install arm-gcc-binutils  # macOS
# 或从 ARM 官网下载: https://developer.arm.com/downloads/-/gnu-rm

# 2. 验证工具链
arm-none-eabi-gcc --version
# 预期: arm-none-eabi-gcc (GNU Arm Embedded Toolchain 13.2) ...

# 3. 安装 yuleOSH (如尚未安装)
pip install yuleosh
```

### 2.2 交叉编译构建

```bash
# 配置为 S32K312 目标
cmake -S . -B build-s32k312 \
  -DYULE_PLATFORM_S32K312=ON \
  -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-arm-none-eabi.cmake

# 编译
cmake --build build-s32k312 -j4

# 验证编译产物
arm-none-eabi-objdump -h build-s32k312/src/yuleasr.elf | head -20
arm-none-eabi-size build-s32k312/src/yuleasr.elf
```

### 2.3 CMake 配置选项

| 选项 | 默认值 | 说明 |
|------|:------:|------|
| `YULE_PLATFORM_S32K312` | OFF | 启用 S32K312 交叉编译 |
| `YULE_PLATFORM_X86` | ON | 默认 x86 本地开发 |
| `ENABLE_COVERAGE` | OFF | 覆盖率编译模式 (仅 x86) |
| `ENABLE_MISRA_CHECK` | OFF | CI 中启用 MISRA 检查 |
| `TOOLCHAIN_PREFIX` | `arm-none-eabi-` | 交叉编译工具前缀 |

### 2.4 工具链文件

`cmake/toolchain-arm-none-eabi.cmake`:

```cmake
set(CMAKE_SYSTEM_NAME Generic)
set(CMAKE_SYSTEM_PROCESSOR arm)

set(TOOLCHAIN_PREFIX arm-none-eabi-)
set(CMAKE_C_COMPILER ${TOOLCHAIN_PREFIX}gcc)
set(CMAKE_CXX_COMPILER ${TOOLCHAIN_PREFIX}g++)

set(CMAKE_C_FLAGS "${CMAKE_C_FLAGS} -mcpu=cortex-m4 -mthumb -mfloat-abi=hard -mfpu=fpv4-sp-d16")
set(CMAKE_C_FLAGS "${CMAKE_C_FLAGS} -ffunction-sections -fdata-sections -Wall -std=c11")

set(CMAKE_EXE_LINKER_FLAGS "-Wl,--gc-sections -Wl,-Map=output.map")

set(CMAKE_FIND_ROOT_PATH_MODE_PROGRAM NEVER)
set(CMAKE_FIND_ROOT_PATH_MODE_LIBRARY ONLY)
set(CMAKE_FIND_ROOT_PATH_MODE_INCLUDE ONLY)
```

## 3 内存映射

### 3.1 物理内存

| 区域 | 起始地址 | 大小 | 用途 |
|------|---------|:----:|------|
| Flash (程序) | 0x0000_0000 | 512 KB | 代码 + const 数据 + 配置表 |
| Data Flash (模拟 EEPROM) | 0x1000_0000 | 16 KB | NvM 数据存储 |
| SRAM_L | 0x1FFF_8000 | 32 KB | 系统 RAM (快速访问) |
| SRAM_H | 0x2000_0000 | 32 KB | 系统 RAM (高地址, 自动初始化) |
| 外设 | 0x4000_0000 | ~1 MB | 外设寄存器 |
| HSE SRAM | 0x5000_0000 | 32 KB | 安全引擎内存 |

### 3.2 链接脚本分区

```ld
/* docs/platform/s32k312_memory.ld */

MEMORY
{
    FLASH_CODE   (rx)  : ORIGIN = 0x00000000, LENGTH = 480K
    FLASH_CONFIG (rx)  : ORIGIN = 0x00078000, LENGTH = 32K
    DATA_FLASH   (rx)  : ORIGIN = 0x10000000, LENGTH = 16K
    SRAM         (rw)  : ORIGIN = 0x1FFF8000, LENGTH = 64K
}
```

## 4 BSP 与启动

### 4.1 启动序列

```
硬件复位
  → 启动 ROM Bootloader (片上 ROM)
  → 跳转到 main() (Flash 起始地址)
  → SystemInit() — 时钟配置 (80 MHz PLL)
  → MPU 初始化
  → C Runtime 初始化 (BSS 清零, DATA 加载)
  → OS 初始化 (EcuM_Init)
  → BSW 模块初始化
  → 任务调度开始
```

### 4.2 MCAL 配置

| MCAL 外设 | 使用的通道/实例 | 功能 |
|----------|---------------|------|
| CAN0 | CAN-FD 500kbps | 主要 CAN 总线 |
| CAN1 | CAN-FD 250kbps | 冗余 CAN 总线 |
| LIN0 | LIN 19200bps | 低速 LIN 总线 |
| SPI0 | 4 MHz | 外设通信 |
| PIT0 | 1 ms 周期 | 系统 tick |
| GPT0 | 10 ms 周期 | WdgM 代数 |
| WDOG | 100 ms 超时 | 系统看门狗 |

## 5 安全特性映射

### 5.1 S32K312 安全特性与 yuleASR 映射

| S32K312 特性 | yuleASR 利用 | 安全目标 |
|-------------|-------------|---------|
| MPU (8 区域) | ASIL B/QM 隔离 (v2.0) | SG-001/SG-002 |
| RAM ECC (单比特纠错/双比特检测) | 所有 RAM 访问自动保护 | SG-001 |
| Flash ECC (单比特纠错/双比特检测) | 代码和数据完整性 | SG-001 |
| HSE_B (安全引擎) | CryIf/SecOC 密码操作 + 密钥管理 | SG-001 |
| Lockstep (双核锁步) | CPU 故障检测 (硬件级) | SG-002 |
| WDOG (独立看门狗) | WdgM 硬件触发 | SG-002 |
| 时钟监控 (CMU) | PLL 故障检测 | SG-002 |
| 电压监控 (PMC) | 电源跌落检测 | SG-003 |

### 5.2 硬件限制

| 限制 | 影响 | 缓解 |
|------|------|------|
| 无 MMU (MPU 无虚拟地址) | 无完全内存管理 | 静态分区 (见 mpu-partition.md) |
| SRAM 仅 64 KB | 有限 ASIL B 数据隔离空间 | 16 KB 分配给 ASIL B |
| 单核 (无第二核用于安全监控) | 安全监控与功能代码同核 | 中断优先级 + NMI 隔离 |
| HSE 内存 32 KB 且隔离 | 安全操作无系统内存交互 | HSE 操作经回调返回 |

## 6 验证与测试

### 6.1 编译验证

```bash
# 编译验证 (无需硬件)
cmake -S . -B build-s32k312 -DYULE_PLATFORM_S32K312=ON -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-arm-none-eabi.cmake
cmake --build build-s32k312 2>&1 | tail -10

# 二进制分析
arm-none-eabi-objdump -d build-s32k312/src/yuleasr.elf > yuleasr.dis   # 反汇编
arm-none-eabi-readelf -s build-s32k312/src/yuleasr.elf > yuleasr.sym   # 符号表
arm-none-eabi-size build-s32k312/src/yuleasr.elf                        # 段大小
```

### 6.2 资源使用

| 资源 | 预估使用 | 可用 | 余量 |
|------|:--------:|:----:|:----:|
| Flash (代码) | ~200 KB | 512 KB | 60% |
| Flash (数据) | ~8 KB | 16 KB | 50% |
| SRAM (全局) | ~30 KB | 64 KB | 53% |
| SRAM (栈) | ~8 KB (每任务 1K×8) | — | 需调整 |

> 注: 以上为估算值, 需在交叉编译后通过 `arm-none-eabi-size` 精确测量。

## 7 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `arm-none-eabi-gcc: command not found` | 工具链未安装 | `brew install arm-gcc-binutils` |
| 链接错误: `undefined reference to SystemInit` | 启动文件缺失 | `src/bsp/s32k312/startup.c` 需包含 SystemInit |
| 链接错误: 内存溢出 | SRAM/Flash 超限 | 优化代码大小, 使用-Os编译 |
| cmake 报 platform 不支持 | CMakeLists.txt 未配置 S32K312 | 检查 YULE_PLATFORM_S32K312 选项 |
| 反汇编看到 BLX 指令无对应函数 | 弱符号未链接 | 检查链接顺序 |
