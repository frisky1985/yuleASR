# 变更管理（docs/changes/）

> 依据 .ai-rules.md 第六章：所有需求变更走标准化流程。

## 流程

1. 新建 `docs/changes/[变更名称]/` 目录
2. `proposal.md`：变更背景 + 影响范围 + 验收标准
3. `tasks.md`：拆分具体实现任务（勾选式）
4. 先更新规范文档 → 再按任务清单生成代码
5. 变更完成后归档，保证可追溯

## 模板

```
docs/changes/[change-name]/
├── proposal.md    # 背景/影响/验收
└── tasks.md       # 任务拆分
```
