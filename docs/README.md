# YuleASR 文档中心

本文档中心整理了 yuleASR 项目的所有文档，按照清晰的功能分类进行组织。

## 目录结构

```
docs/
├── architecture/       # 架构文档 - 系统架构和设计概览
├── api/               # API参考文档 - API接口规范和使用说明
├── modules/           # 模块文档 - AutoSAR 各模块详细文档
├── guides/            # 使用指南 - 配置、开发和故障排除指南
├── design/            # 设计文档 - 详细设计决策和策略
├── specs/             # 规范文档 - 项目规范和计划
├── reports/           # 项目报告 - 各类分析报告和进度报告
└── external/          # 外部资料 - 第三方文档和参考资料
```

## 各目录说明

### architecture/
系统架构文档，包含：
- 整体架构概览
- 操作系统相关文档
- 模块架构说明

### api/
API接口文档，包含：
- API参考手册
- COM模块API
- Crypto加密API
- DCM传输服务

### modules/
AutoSAR标准模块文档，包含：
- 基础软件(BSW)各模块文档
- 服务层模块文档
- ECU抽象层模块文档

### guides/
使用指南和手册，包含：
- 开发指南
- 配置指南
- 故障排除手册
- 安全分析文档
- MISRA合规指南

### design/
设计文档，包含：
- 架构设计决策
- 数据流设计
- 错误处理策略
- 内存管理设计
- 测试策略
- 模块级详细设计文档（`design/modules/`）

### specs/
规范和计划文档，包含：
- 改进建议
- 覆盖率报告
- 实施计划
- 变更日志

### reports/
项目报告，包含：
- 合规性报告
- 验证报告
- 代码审查报告
- 静态分析报告
- 进度报告

### external/
外部资料和参考文档，包含：
- 爬取的AutoSAR博客文章
- S32K312学习资料
- 第三方参考资料
