# 版本历史

## [1.1.0] - 2026-04-29

### 概述

此版本新增 4 个核心模块，完善了车载网络支持能力。

### 新增功能

#### MCAL 层新驱动 (3 个)

- **Eth** - 以太网驱动 (Module ID: 0x53) 🆕
  - 支持 10/100/1000 Mbps 操作速率
  - MII/RMII 接口支持
  - MAC 地址管理 (设置/获取/过滤)
  - 发送/接收中断处理
  - PHY MII 接口读写
  - 缓冲区管理
  
- **Icu** - 输入捕获驱动 (Module ID: 0x10) 🆕
  - 4 种测量模式支持:
    - 信号边沿检测 (上升/下降/双边沿)
    - 时间戳捕获
    - 信号测量 (周期/脉宽/占空比)
    - 边沿计数
  - 唤醒功能支持
  - 多通道配置
  
- **Ocu** - 输出比较驱动 (Module ID: 0x7A) 🆕
  - 绝对/相对阈值设置
  - 4 种引脚动作:
    - SET_HIGH - 比较匹配时置高
    - SET_LOW - 比较匹配时置低
    - TOGGLE - 比较匹配时翻转
    - HOLD - 保持当前状态
  - 通知回调机制
  - ASIL-D 安全等级兼容

#### ECUAL 层新模块 (1 个)

- **FrTp** - FlexRay 传输协议 (Module ID: 0x2D) 🆕
  - ISO TP 分段传输协议支持
    - 单帧 (Single Frame, SF)
    - 首帧 (First Frame, FF)
    - 连续帧 (Consecutive Frame, CF)
    - 流量控制 (Flow Control, FC)
  - 多连接管理
  - 可配置超时管理 (N_As, N_Bs, N_Cs, N_Ar, N_Br, N_Cr)
  - 流量控制参数设置 (Block Size, STmin)
  - 传输取消支持

### 车载网络支持

完整支持所有主流车载网络:

| 网络类型 | 状态 | 模块 |
|:---------|:-----|:-----|
| CAN | ✅ 完成 | Can, CanIf, CanTp |
| FlexRay | ✅ 完成 | FrIf, FrTp |
| Ethernet | ✅ 完成 | Eth, EthIf |
| LIN | ✅ 完成 | LinIf |

### 质量保证

- **MISRA C:2012 合规性**
  - 所有新模块通过 MISRA C:2012 规范检查
  - 98% 以上的代码覆盖率
- **单元测试**
  - 新增 100+ 单元测试用例
  - 覆盖所有新模块的核心功能

## [1.0.0] - 2026-04-15

### 概述

首个正式发布版本，提供完整的 AutoSAR BSW 基础软件栈实现。

### 新增功能

#### MCAL 层 (9 个模块)

- **Mcu** - 微控制器驱动
  - 初始化、时钟配置、复位控制
  - 低功耗模式管理
  
- **Port** - 端口驱动
  - 引脚配置和方向控制
  
- **Dio** - 数字 I/O 驱动
  - 数字输入/输出控制
  
- **Can** - CAN 驱动
  - CAN 控制器初始化
  - 消息发送/接收
  - 中断处理
  
- **Spi** - SPI 驱动
  - SPI 通信接口
  
- **Gpt** - 通用定时器驱动
  - 定时器功能
  
- **Pwm** - PWM 驱动
  - PWM 信号生成
  
- **Adc** - ADC 驱动
  - 模数转换功能
  
- **Wdg** - 看门狗驱动
  - 看门狗监控

#### ECUAL 层 (9 个模块)

- **CanIf** - CAN 接口
  - CAN 硬件抽象
  - PDU 路由
  - 总线关闭处理
  
- **IoHwAb** - I/O 硬件抽象
  - 信号抽象和处理
  
- **CanTp** - CAN 传输协议
  - ISO-TP 协议支持
  
- **EthIf** - 以太网接口
  - 以太网通信
  
- **MemIf** - 存储器接口
  - 统一存储器访问
  
- **Fee** - Flash EEPROM 仿真
  - Flash 模拟 EEPROM
  
- **Ea** - EEPROM 抽象
  - EEPROM 访问抽象
  
- **FrIf** - FlexRay 接口
  - FlexRay 通信
  
- **LinIf** - LIN 接口
  - LIN 通信

#### Service 层 (5 个模块)

- **Com** - 通信服务
  - 基于信号的通信
  - 信号组管理
  - IPDU 传输控制
  
- **PduR** - PDU 路由器
  - 路由表管理
  - 向上/向下路由
  - FIFO 队列管理
  
- **NvM** - NVRAM 管理器
  - 块管理
  - CRC 校验
  - 作业队列
  
- **Dcm** - 诊断通信管理器
  - UDS 服务支持
  - 会话管理
  - 安全访问控制
  
- **Dem** - 诊断事件管理器
  - 事件状态管理
  - DTC 管理
  - 老化机制

#### RTE 层 (1 个模块)

- **Rte** - 运行时环境
  - 组件通信接口
  - 数据类型定义
  - 任务调度器
  - COM/NVM 接口

## 版本编号规则

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/) 规范：

```
版本格式：主版本号.次版本号.修订号

主版本号：不兼容的 API 修改
次版本号：向下兼容的功能新增
修订号：向下兼容的问题修正
```

### 示例

- `1.0.0` - 初始发布
- `1.1.0` - 新增功能
- `1.1.1` - 问题修复
- `2.0.0` - 不兼容变更
