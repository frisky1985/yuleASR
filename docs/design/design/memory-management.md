# 内存管理设计

## 内存分区

```
┌──────────────────────────────────────────────┐
│              RAM                                    │
│  ┌───────────────┐  ┌───────────────┐  ┌───────────────┐  │
│  │   代码段     │  │   数据段     │  │   堆栈      │  │
│  │  (Text)    │  │  (Data)    │  │  (Stack)   │  │
│  └───────────────┘  └───────────────┘  └───────────────┘  │
├──────────────────────────────────────────────┤
│              非易失性存储 (Flash/EEPROM)            │
│  ┌───────────────────────────────────────┐             │
│  │           NV 数据存储                           │             │
│  └───────────────────────────────────────┘             │
└──────────────────────────────────────────────┘
```

## 内存分配策略

### 静态分配

所有内存在编译时确定，运行时不动态分配

### MemMap 机制

```c
#define MEMMAP_ERROR

/* 开始段定义 */
#define <ModuleName>_START_SEC_VAR_INIT_UNSPECIFIED
#include "MemMap.h"

/* 变量定义 */
static uint8 MyVariable = 0;

/* 结束段定义 */
#define <ModuleName>_STOP_SEC_VAR_INIT_UNSPECIFIED
#include "MemMap.h"
```

## NV 存储管理

```
Application → NVM → MEMIF → FEE → FLS
```

### 数据块类型

1. **Native**: 原始数据块
2. **Redundant**: 写时备份
3. **Dataset**: 多版本数据
