# 配置系统设计

## 配置层次

```
┌──────────────────────────────────────────────┐
│              编译时配置 (Pre-compile)                    │
│  - *.h 头文件中的宏定义                                  │
├──────────────────────────────────────────────┤
│              链接时配置 (Link-time)                       │
│  - *_Lcfg.c 配置表                                      │
├──────────────────────────────────────────────┤
│              后构建配置 (Post-build)                      │
│  - *_PBcfg.c 配置结构体                                │
└──────────────────────────────────────────────┘
```

## 配置文件结构

```
src/bsw/services/<module>/
├─── include/
│   ├─── <Module>_Cfg.h      /* 编译时配置 */
│   └─── <Module>.h          /* 公共头文件 */
├─── src/
│   ├─── <Module>.c          /* 主源文件 */
│   └─── <Module>_Lcfg.c     /* 链接时配置 */
```

## 配置工具链

```
ARXML → 生成器 → 配置代码 (C文件)
```
