## 1 引言

### 1.1 目的

本 Safety Case 文档采用 **Goal Structuring Notation (GSN)** 框架，系统性组织 yuleASR AUTOSAR BSW 平台的安全论据。目标是为 ISO 26262 审核和 ASPICE 评估提供完整、可追溯的安全论证链，明确 Goal (目标) → Strategy (策略) → Solution (解决方案) → Context (上下文) 的论证结构。

### 1.2 GSN 符号说明

```
┌─────────────────┐
│      G-xx       │  Goal (目标) — 待证明的声明
│   "描述文本"    │
└────────┬────────┘
         │  ↓ [策略分解]
┌─────────────────┐
│      S-xx       │  Strategy (策略) — 论证策略
│   "描述文本"    │
└────────┬────────┘
         │  ↓ [上下文]
┌─────────────────┐
│      C-xx       │  Context (上下文) — 背景假设/引用
│   "描述文本"    │
└────────┬────────┘
         │  ↓ [证据]
┌─────────────────┐
│      Sn-xx      │  Solution (解决方案/证据) — 具体证据
│   "引用文档"    │
└─────────────────┘

┌─────────────────┐
│      J-xx       │  Justification (正当理由) — 额外论证
│   "理由文本"    │
└─────────────────┘
```
