# yuleASR — AUTOSAR Classic BSW Platform

yuleASR 是**上海予乐电子科技有限公司**开发并开源的 AUTOSAR Classic Platform 基础软件平台，提供完整的 MCAL、ECUAL、Services 三层 BSW 模块实现。

## 核心特性

- **96 个 BSW 模块**：MCAL 21 + ECUAL 29 + Services 46，全覆盖
- **符合 AUTOSAR 4.x / R20-11 标准**
- **内建 DDS 中间件**：OMG DDS v1.4 协议支持
- **完整诊断协议栈**：DCM/DEM + UDS + DoIP + DoCAN
- **ARXML 工具链**：统一 CLI 解析/生成/检查
- **目标平台**：NXP S32K312 (ARM Cortex-M7)
