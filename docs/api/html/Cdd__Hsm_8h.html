Detailed Description

Complex Driver — Hardware Security Module (HSM) Interface.

Version
1.0.0
Date
2026-07-23

Hardware Security Module complex driver for S32K312. Provides hardware-accelerated cryptographic operations, secure key management, TRNG, and secure boot verification via the on-chip HSM (CSEc / SHE-compatible security module).

Responsibilities:

  • HSM hardware initialization / de-initialization
  • AES-GCM / SHA-256 / ECDSA / ECDH hardware acceleration
  • Secure key storage management
  • True Random Number Generation (TRNG)
  • Secure boot signature verification
  • HSM self-test and health monitoring

@ASIL-D Safety Level — Complex Device Driver: HSM
