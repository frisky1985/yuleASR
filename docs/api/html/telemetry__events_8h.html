Detailed Description

埋点事件定义

事件ID分配:

  • 0x00-0x0F: System
  • 0x10-0x1F: EcuM
  • 0x20-0x2F: BswM
  • 0x30-0x4F: DDS
  • 0x50-0x6F: Ethernet
  • 0x70-0x7F: Security
  • 0x80-0x8F: Diagnostics
  • 0x90-0x9F: OTA
  • 0xA0-0xFF: User-defined
