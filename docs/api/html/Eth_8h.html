Detailed Description

Ethernet Driver.

Version
1.0.0

Ethernet MAC driver for AUTOSAR MCAL layer. Based on AUTOSAR Classic Platform 4.4.0, Eth driver specification. Supports 10/100/1000 Mbps operation with ASIL-D safety level compatibility.

2024-2026 Shanghai Yule Electronics Technology Co., Ltd.
