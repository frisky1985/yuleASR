20/*=============================================================================
21 * Memory Map Overview
22 *
23 * Flash (alias): 0x00000000 - 0x003FFFFF (4 MB)
24 * Flash (primary): 0x00400000 - 0x007FFFFF (4 MB)
25 * SRAM_L: 0x1FFF0000 - 0x1FFFFFFF (64 KB)
26 * SRAM_U: 0x20000000 - 0x2007FFFF (512 KB)
27 * AIPS0: 0x40000000 - 0x4007FFFF (512 KB)
28 * AIPS1: 0x40080000 - 0x400FFFFF (512 KB)
29 * AIPS2: 0x40100000 - 0x4017FFFF (512 KB)
30 * AIPS3: 0x40180000 - 0x401FFFFF (512 KB)
31 * AIPS4: 0x40200000 - 0x4027FFFF (512 KB)
32 * AIPS5: 0x40280000 - 0x402FFFFF (512 KB)
33 * GPIO: 0x40810000 - 0x4081FFFF (64 KB)
34 * HSM: 0x40460000 - 0x4046FFFF (64 KB)
35 *============================================================================*/
