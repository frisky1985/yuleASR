Detailed Description

Expression tree node (flat table, referenced by index).

Leaf nodes (MODE_EQUALS / MODE_NOT_EQUALS) use PortIndex + CompareValue. Logical nodes use LeftIndex/RightIndex (NOT uses LeftIndex only).
