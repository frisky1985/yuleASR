Detailed Description

S32K312 ECC中断处理头文件

实现ECC错误的中断级别处理，包括:

  • 单位错误纠正 (可恢复)
  • 双位错误检测 (严重故障)
  • NvM数据损坏处理

@ASIL-D Safety Level
