Detailed Description

NvM ECC故障处理模块

提供NvM特定的ECC错误处理策略，包括：

  • 块级别数据损坏检测
  • 自动数据恢复 (ROM备份 -> RAM)
  • 写入时验证失败处理
  • 读写RAM中断保护

@ASIL-D Safety Level
