Detailed Description

VLAN configuration — aligned with B1 TcpIp_VlanConfigType (VlanEnabled/VlanId/VlanPriority/DropUntagged); VlanPriority carries the 802.1p PCP (VID-PCP mapping), DropUntagged gates untagged ingress. PortMask is the VLAN member table (bitmask of member ports).
