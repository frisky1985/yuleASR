bl_rollback_storage_error_t(*) bl_rollback_storage_api_s::confirm_health(void *ctx, uint32_t version, bool ok)

业务健康确认 (RS-OTA-05 P1, App 健康检查通过/失败后调用)

ok==true 且 version==待确认版本 → 置 health_confirmed=true 落盘; ok==false → 置 health_confirmed=false 落盘 (pending 保持, 等待 watchdog/boot_attempt 超限自动回滚)。

version本次健康检查对应的固件版本
okTRUE=业务健康; FALSE=业务异常
