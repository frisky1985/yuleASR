Detailed Description

Crypto Interface Module - AutoSAR Service Layer.

Version
1.0.0
Date
2026-05-01
Author
YuleTech
Copyright
Copyright (c) 2026 YuleTech

Provides an AUTOSAR CRYIF module offering services for cryptographic operations abstraction between CSM and Crypto Driver. Following AutoSAR Classic Platform 4.x standard.
