AutoSAR Standard: CAN Time Synchronization (CANTSYN) Module ID: 0xA4U Layer: Service Layer

The CanTSyn module provides services for time synchronization over CAN bus. It supports both Time Master and Time Slave functionality for global time distribution in distributed automotive systems.

Key Features:

  • Time Master: Transmits SYNC and FUP messages
  • Time Slave: Receives SYNC/FUP and adjusts local time
  • User Data (OCS) support for application-specific time data
  • Microsecond-level synchronization precision
  • Integration with StbM (Synchronized Time-base Manager)
