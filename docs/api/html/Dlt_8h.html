Detailed Description

DLT (Diagnostic Log and Trace) 模块主头文件

提供符合 AutoSAR Classic Platform 4.x 规范的诊断日志和跟踪服务

功能特性:

  • 日志消息传输 (Log Messages)
  • 跟踪消息传输 (Trace Messages)
  • 多种传输协议支持 (UDP/TCP/SOME/IP)
  • 消息优先级和过滤
  • 应用注册和管理
