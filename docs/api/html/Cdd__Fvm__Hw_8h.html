Detailed Description

Complex Driver — Flash Virtual Memory (FVM) Hardware Abstraction.

Version
1.0.0
Date
2026-08-09

Hardware backend interface of the FVM complex driver (same layering pattern as Fls_Hw.h). The module logic in Cdd_Fvm.c never touches flash directly — it always goes through this interface.

Two backends are provided (selected by CDD_FVM_BACKEND in Cdd_Fvm_Cfg.h):

  • CDD_FVM_BACKEND_RAM : in-RAM mirror (native build / SIL / unit tests)
  • CDD_FVM_BACKEND_FLS : real flash through the MCAL Fls driver (target)

@ASIL-D Safety Level
