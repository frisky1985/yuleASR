Detailed Description

Ethernet Time Synchronization (EthTSyn) — AUTOSAR BSW Module.

AUTOSAR R21-11 §12.9: EthTSyn provides IEEE 802.1AS / gPTP time synchronization over Ethernet.

This is a lightweight stub for COMPLETENESS — not full implementation.
