13/************************************************************************************
14 * File: LinSM.h
15 * Description: LIN State Manager - Main Header File
16 * AUTOSAR Version: 4.4.0
17 *
18 * Module: LinSM (LIN State Manager)
19 * Purpose: Manages the state of LIN channels and schedule tables
20 *
21 * The LinSM (LIN State Manager) is responsible for:
22 * - Managing communication modes (NO_COM, FULL_COM) per LIN channel
23 * - Schedule table switching and management
24 * - Sleep/wake-up handling for LIN channels
25 * - Integration with ComM for communication mode management
26 ************************************************************************************/
