Detailed Description

看门狗管理模块头文件

功能: 提供看门狗监控、监督定时、安全状态管理 支持窗口看门狗(WWD)和独立看门狗(IWD) 与Lockstep和RamSafety安全模块集成

@ASIL-D Safety Level

yuleASR Team
