Std_ReturnType Com_TriggerIPDUSend ( Com_IPduIdType PduId)

Trigger immediate I-PDU transmission.

Schedules an I-PDU for immediate transmission regardless of its configured transmission mode. The actual transmission occurs in the next call to Com_MainFunctionTx.

E_OK if triggered successfully, E_NOT_OK otherwise
