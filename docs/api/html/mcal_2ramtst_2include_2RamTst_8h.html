Detailed Description

RAM Test Driver - AUTOSAR MCAL Module.

Version
2.0.0
Date
2026-07-19
Author
YuleTech
Copyright
Copyright (c) 2026 YuleTech

AUTOSAR RAM Test (RamTst) module interface. Provides memory test services including March-C/GALPAT/Walkpath algorithms for SRAM testing with DET error reporting.
