Detailed Description

EEPROM Driver - AUTOSAR MCAL Module.

Version
2.0.0
Date
2026-07-19
Author
YuleTech
Copyright
Copyright (c) 2026 YuleTech

AUTOSAR EEPROM (Eep) module interface for emulated EEPROM using Flash or RAM backing store. Supports asynchronous read/write/erase operations with DET error reporting.
