10 * Shared static memory pool backing the mbedTLS buffer allocator
11 * (MBEDTLS_MEMORY_BUFFER_ALLOC_C). Replaces the implicit libc
12 * calloc()/free() inside mbedTLS so that no heap is used at all
13 * on the S32K312 bare-metal target.
14 *
15 * Design (遵循已定型静态池范式):
16 * - 编译期固定 buffer（CRYPTO_MBEDTLS_MEM_POOL_SIZE，默认 32KB，.bss）
17 * - mbedTLS 官方 buffer allocator 负责块管理（header+magic+verify），
18 * 等价于模块分池+位图管理范式的 mbedTLS 原生实现
19 * - 幂等 Init：任何 mbedTLS 使用方在初始化阶段调用一次即可，
20 * 多个使用方重复调用安全（first-call-wins）
21 *
22 * MISRA C:2012 依据:
23 * - Dir 4.12 (required): 运行时零动态分配 — 仅初始化期一次性建池
24 * - Rule 21.3 (advisory): 生产代码不引用 malloc/free/calloc
25 * - Rule 18.7 (required): 显式定长数组，无柔性数组
26 * - Rule 18.8 (required): 无 VLA，全部编译期常量
27 *********************************************************************************************************************/
