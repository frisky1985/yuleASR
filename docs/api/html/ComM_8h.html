Detailed Description

AUTOSAR Communication Manager API Header.

Version
1.0.0

AUTOSAR Communication Manager (ComM) manages communication modes and ECU states. Provides API for requesting communication modes, managing channel states, Partial Network Cluster (PNC) handling, and bus wake-up support.
