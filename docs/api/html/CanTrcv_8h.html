◆ CanTrcv_TrcvWakeupReasonType

enum CanTrcv_TrcvWakeupReasonType

CAN Transceiver wake-up reason.

Indicates the source of a wake-up event detected by the transceiver.

Enumerator
CANTRCV_WU_ERROR 

No wake-up reason available or cleared.

CANTRCV_WU_BY_BUS 

Wake-up caused by bus activity.

CANTRCV_WU_BY_PIN 

Wake-up caused by external pin transition (e.g., local wake-up).

CANTRCV_WU_INTERNALLY 

Wake-up caused internally (e.g., power-on or software).

CANTRCV_WU_NOT_SUPPORTED 

Wake-up reason not supported by hardware.

CANTRCV_WU_POWER_ON 

Wake-up caused by bus activity in power-on state.

CANTRCV_WU_BY_SYSERR 

Wake-up caused by reset (e.g., after overtemperature).

CANTRCV_WU_RESERVED 

Reserved value for future extensions.
