Detailed Description

Selective wake-up filter of a transceiver channel.

A received frame passes the PN filter when (CanId AND CanIdMask) lies inside the inclusive range [(CanIdRangeLower AND CanIdMask), (CanIdRangeUpper AND CanIdMask)]. The filter is armed per transceiver via CanIf_SetPnWakeupFilter.
