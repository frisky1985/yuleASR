# J1939Tp (J1939 Transport Layer) 使用手册

## 概述

J1939Tp是基于SAE J1939标准的传输层模块，支持大数据包的传输，包括：
- BAM (Broadcast Announce Message) 广播传输
- RTS/CTS (Request to Send/Clear to Send) 点对点传输

## 功能特点

| 特性 | 说明 |
|------|------|
| BAM传输 | 支持最大8字节的广播报文 |
| RTS/CTS传输 | 支持最天1785字节的可靠传输 |
| 超时处理 | 可配置的发送和接收超时 |
| 流量控制 | 支持CTS中指定的包数限制 |

## 配置方法

### 1. 配置参数 (J1939Tp_Cfg.h)

```c
/* 通道数量 */
#define J1939TP_CHANNEL_COUNT       4

/* 超时时间 (毫秒) */
#define J1939TP_T1_TIMEOUT          750   /* CTS等待超时 */
#define J1939TP_T2_TIMEOUT          1250  /* 数据等待超时 */
#define J1939TP_T3_TIMEOUT          1250  /* 数据发送间隔 */
#define J1939TP_T4_TIMEOUT          1050  /* 下一次CTS等待 */
#define J1939TP_BAM_TIMEOUT         500   /* BAM数据间隔 */

/* 重试次数 */
#define J1939TP_MAX_RETRIES         3
```

### 2. 通道配置

```c
const J1939Tp_ChannelConfigType J1939Tp_ChannelConfig[] = {
    {
        .ChannelId = 0,
        .ChannelType = J1939TP_BAM,      /* 或 J1939TP_RTS_CTS */
        .FcNPdu = 0,                      /* 流量控制PDU */
        .DtNPdu = 1,                      /* 数据PDU */
        .CmNPdu = 2,                      /* 连接管理PDU */
        .TxPdu = 3,                       /* 传输层Tx PDU */
        .RxPdu = 4,                       /* 传输层Rx PDU */
        .MaxMessageLength = 1785
    },
    /* 更多通道... */
};
```

## API参考

### 核心函数

| 函数 | 功能 | 参数 | 返回值 |
|------|------|------|---------|
| `J1939Tp_Init` | 初始化模块 | ConfigPtr | void |
| `J1939Tp_Transmit` | 发送数据 | TxPduId, PduInfoPtr | Std_ReturnType |
| `J1939Tp_RxIndication` | 接收通知 | RxPduId, PduInfoPtr | void |
| `J1939Tp_MainFunction` | 主函数 | void | void |
| `J1939Tp_CancelTransmit` | 取消发送 | TxPduId | Std_ReturnType |

### 回调函数

```c
/* 发送完成通知 */
void J1939Tp_TxConfirmation(PduIdType TxPduId, Std_ReturnType result);

/* 接收完成通知 */
void J1939Tp_RxIndication(PduIdType RxPduId, const PduInfoType* PduInfoPtr);
```

## 使用示例

### BAM传输示例

```c
#include "J1939Tp.h"

void SendBAMMessage(void) {
    uint8 data[40] = {
        0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07, 0x08,
        0x09, 0x0A, 0x0B, 0x0C, 0x0D, 0x0E, 0x0F, 0x10,
        /* ... 更多数据 */
    };
    
    PduInfoType pdu;
    pdu.SduDataPtr = data;
    pdu.SduLength = 40;
    pdu.MetaDataPtr = NULL;
    
    /* 发送BAM消息 */
    Std_ReturnType result = J1939Tp_Transmit(BAM_CHANNEL_ID, &pdu);
    
    if (result == E_OK) {
        /* 发送成功，等待TxConfirmation */
    }
}
```

### RTS/CTS传输示例

```c
void SendRTSMessage(void) {
    uint8 data[100] = {
        /* 大数据包 */
    };
    
    PduInfoType pdu;
    pdu.SduDataPtr = data;
    pdu.SduLength = 100;
    
    /* 发送RTS请求 */
    Std_ReturnType result = J1939Tp_Transmit(RTS_CHANNEL_ID, &pdu);
    
    /* 等待CTS响应后自动发送数据 */
}
```

### 接收处理示例

```c
void J1939Tp_RxIndication(PduIdType RxPduId, const PduInfoType* PduInfoPtr) {
    if (RxPduId == MY_RX_PDU) {
        /* 处理接收的数据 */
        ProcessReceivedData(PduInfoPtr->SduDataPtr, PduInfoPtr->SduLength);
    }
}
```

## 问题排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 发送失败 (E_NOT_OK) | 通道正忙 | 检查通道状态或等待完成 |
| 超时错误 | 网络延迟或对端无响应 | 调整超时参数或检查连接 |
| 数据重组错误 | 丢包或序号错误 | 检查物理层连接 |
| CTS拒绝 | 对端资源不足 | 减小数据量或等待重试 |

## 性能考虑

- BAM传输不提供确认机制，适合非关键数据
- RTS/CTS开销大于8字节的数据传输
- 调整T1-T4超时参数适应网络延迟
