J1939Tp - J1939 Transport Protocol Module

Overview​

J1939Tp implements the SAE J1939-21 Transport Protocol for commercial vehicle multi-frame message transmission over CAN bus. This module enables transmission of Parameter Groups (PGs) larger than 8 bytes.

AUTOSAR Version​

  • AUTOSAR Classic Platform 4.4.0
  • SAE J1939-21 (Transport Layer)

Features​

Transmission Modes​

  1. BAM (Broadcast Announce Message) - Connectionless broadcast transmission

    • No handshake required
    • Transmitter sends BAM announcement followed by DT packets
    • Any node can receive

  2. CMDT (Connection Mode Data Transfer) - RTS/CTS session

    • RTS (Request to Send) - initiates session
    • CTS (Clear to Send) - receiver ready indication
    • DT (Data Transfer) - segmented data packets
    • EOM ACK - End of Message Acknowledgment

  3. Direct NPDU - Single frame transmission (<= 8 bytes)

    • Bypasses transport protocol
    • Direct transmission to CanIf

Main APIs​

APIFunction
J1939Tp_Init()Initialize the module
J1939Tp_DeInit()Deinitialize the module
J1939Tp_GetVersionInfo()Get module version info
J1939Tp_MainFunction()Periodic processing (10ms)
J1939Tp_Transmit()Request TP transmission
J1939Tp_CancelTransmit()Cancel ongoing transmission
J1939Tp_CancelReceive()Cancel ongoing reception
J1939Tp_ChangeParameter()Change TP parameters

TP.CM Control Bytes​

Control ByteValueDescription
RTS0x10Request to Send
CTS0x11Clear to Send
ACK0x13End of Message Ack
BAM0x20Broadcast Announce
ABORT0xFFConnection Abort

Configuration​

Pre-compile​

  • J1939TP_VERSION_INFO_API - Enable version info API
  • J1939TP_DEV_ERROR_DETECT - Enable development error detection
  • J1939TP_BAM_TX/RX_ENABLED - Enable BAM mode
  • J1939TP_CMDT_TX/RX_ENABLED - Enable CMDT mode

Link-time​

  • Connection configurations (RTS/CTS/BAM)
  • PG (Parameter Group) configurations
  • Timeout values (T1, T2, T3, T4)
  • PDU mappings

Post-build​

Not supported

Timeout Parameters​

ParameterDefaultDescription
T1750msResponse timeout
T21250msSend CTS timeout
T31250msSend DT timeout
T41050msCTS hold timeout

Dependencies​

  • DET (Development Error Tracer) - optional
  • CanIf (CAN Interface)
  • PduR (PDU Router)
  • MemMap (Memory mapping)

Usage Example​

#include "J1939Tp.h"

void J1939Tp_Example(void)
{
    /* Initialize the module */
    J1939Tp_Init(&J1939Tp_Config);

    /* Transmit multi-frame message */
    uint8 data[100];
    PduInfoType pduInfo;
    pduInfo.SduDataPtr = data;
    pduInfo.SduLength = 100;

    Std_ReturnType result = J1939Tp_Transmit(2, &pduInfo);

    if (result == E_OK) {
        /* Transmission accepted, process in main function */
        while (1) {
            J1939Tp_MainFunction();
            /* ... other tasks ... */
        }
    }
}

State Machine​

TX Channel States​

  • IDLE → RTS_TX → CTS_RX → DT_TX → EOM_ACK → IDLE
  • IDLE → BAM_TX → DT_TX → IDLE

RX Channel States​

  • IDLE → DT_RX (BAM) → IDLE
  • IDLE → RTS processing → DT_RX → IDLE

Limitations​

  • Maximum TP size: 1785 bytes (255 packets × 7 bytes)
  • Maximum channels: 4 TX + 4 RX (configurable)
  • Broadcast time between BAM frames: 50ms (fixed)
